# Color Blindness Simulator

Drop, paste or pick an image, or paste a list of hex colours, and see it as people with protanopia, deuteranopia, tritanopia or achromatopsia would, all side by side or in a draggable before/after comparison. A severity slider covers the milder, more common anomalous forms. Download or copy the result as PNG.

Uses the Machado, Oliveira & Fernandes (2009) model in linear RGB. Everything runs in the browser; images never leave your device.
