# Tools ⚒️

A collection of small web-based tools and utilities. At least the first iteration of most / all of these is AI generated, usually via Claude Artifacts.

**Browse and search them at [simson.io/tools](https://simson.io/tools/).** The list of tools lives in [`tools.json`](./tools.json); each local tool is a self-contained `index.html` in its own folder. See [`AGENTS.md`](./AGENTS.md) for how to add one.

## All tools

| Tool | Description |
|---|---|
| [Color Background Remover](https://simson.io/tools/color-bg-remover/) | Remove solid-colour backgrounds from images, several colours at once. |
| [CSV to Excel Converter](https://simson.io/tools/csv-to-excel/) | Drop in CSV files, get an Excel workbook. Combines several CSVs into one file, one sheet each. |
| [Perspective & Tilt-Shift Studio](https://simson.io/tools/fancy-screenshot/) | Screenshots to 3D-perspective images with tilt-shift blur, camera angle and FOV, high-res PNG export. |
