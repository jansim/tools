# Tools ⚒️

A collection of small web-based tools and utilities. At least the first iteration of most / all of these is AI generated, usually via Claude Artifacts.

**Browse and search them at [simson.io/tools](https://simson.io/tools/).** The list of tools lives in [`tools.json`](./tools.json); each local tool is a self-contained `index.html` in its own folder. See [`AGENTS.md`](./AGENTS.md) for how to add one.
